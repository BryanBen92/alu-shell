# Shell, init files, variables and expansions

Scripts for the Shell, init files, variables and expansions project.

- `0-alias`: creates an alias named ls with value rm *
- `1-hello_you`: prints hello followed by the current Linux user
- `2-path`: adds /action to the end of PATH
- `3-paths`: counts the number of non-empty directories in PATH
- `4-global_variables`: lists environment variables
- `5-local_variables`: lists local variables, environment variables, and functions
- `6-create_local_variable`: creates a local variable BEST with value School
- `7-create_global_variable`: creates a global variable BEST with value School
- `8-true_knowledge`: adds 128 to the environment variable TRUEKNOWLEDGE
- `9-divide_and_rule`: divides POWER by DIVIDE
- `10-love_exponent_breath`: raises BREATH to the power LOVE
- `11-binary_to_decimal`: converts BINARY from base 2 to base 10
- `12-combinations`: prints all two-letter lowercase combinations except oo
- `13-print_float`: prints NUM formatted to two decimal places
- `14-decimal_to_hexadecimal`: converts DECIMAL from base 10 to base 16
- `15-rot13`: encodes/decodes input using rot13
- `16-odd`: prints every other line of input, starting with the first
- `17-water_and_stir`: adds WATER (base water) and STIR (base stir.), result in base bestchol
